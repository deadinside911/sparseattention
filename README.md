# Sparse Attention

Implementing sparse attention from scratch.

## Local setup

1. Clone the repository

    ```zsh
    git clone git@github.com:deadinside911/sparseattention.git
    cd sparseattention/
    ```

2. Recreate the virtual environment

    ```zsh
    uv sync
    ```

3. Run the program

    ```zsh
    uv run main.py
    ```

    or

    ```zsh
    python main.py
    ```
